@socialize /react-native-meteor is back as a ground-up TypeScript rewrite Some of you may remember @socialize/react-native-meteor , my revamp of inProgress-team’s original React Native client. Unfortunately life gets busy and I’ve been building using other platforms for work projects, so It’s been dormant since 2021, and the ecosystem moved forward. Meteor went 3.x and async-first, React went concurrent, and every dependency the package relied on was abandonware ( ddp.js , minimongo-cache , crypto-js@3 …).
